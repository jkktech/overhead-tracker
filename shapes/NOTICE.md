# Aircraft shapes

The top-view aircraft outlines in this folder come from **AircraftShapesSVG**
by RexKramer1 and contributors: https://github.com/RexKramer1/AircraftShapesSVG

They are licensed under the **GNU General Public License v3.0** (see `LICENSE` in this folder).

Modifications made for this project (by `tools/norm_shapes.py`):
- outlines filled white and detail lines darkened so they can be tinted at runtime
- viewBox cropped to a square around each aircraft
- editor metadata (Inkscape/Sodipodi attributes, titles) removed
- `index.json` added: list of available type codes, look-alike aliases and generic shapes by ADS-B category
